# App privacy and support pages

This is the GitHub Pages user site for nickycho. Keep each app's public pages under its own directory so future apps can be added without URL collisions.

## URL layout

- Photo Sync privacy landing page: https://nickycho.github.io/apps/photo-sync/privacy/
- Localized privacy policies: apps/photo-sync/privacy/{en,zh-Hant,ja,ko}/
- Photo Sync support landing page: https://nickycho.github.io/apps/photo-sync/support/
- Localized support pages: apps/photo-sync/support/{en,zh-Hant,ja,ko}/
- Future app: add a new apps/<app-slug>/ directory.

The Photo Sync policy and support pages are public. Do not store credentials, private user information, or customer files in this repository.

## Publish

GitHub Pages is configured to deploy from branch `main` and the repository root. Changes pushed to `main` are published at https://nickycho.github.io/.
