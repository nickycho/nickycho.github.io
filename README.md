# App privacy and support pages

This is the GitHub Pages user site for nickycho. Keep every app's public pages under its own directory so future apps can be added without URL collisions.

## URL layout

- Photo Sync privacy landing page: https://nickycho.github.io/apps/photo-sync/privacy/
- Localized policies: apps/photo-sync/privacy/{en,zh-Hant,ja,ko}/
- Future app: add a new apps/<app-slug>/ directory.

The Privacy Policy pages are drafts until all legal contact fields are filled and the publisher has reviewed the final text. Do not deploy drafts containing bracketed placeholders.

## Publish

In the repository's GitHub Settings → Pages, choose Deploy from a branch, then main and /(root). GitHub Pages serves this repository at https://nickycho.github.io/.
