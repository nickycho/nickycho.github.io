# 發票載具條碼

把台灣手機條碼放在 App 或主畫面小工具，結帳時快速出示。台灣限定，免費提供。

![發票載具條碼 App 主畫面，畫面使用示範條碼]({{ '/apps/mobile-barcode/assets/iphone17-main.jpg' | relative_url }})

## 功能

- 輸入並保存以「/」開頭的 8 碼手機條碼。
- 在 App 內顯示 Code 39 條碼。
- 將條碼加入中型或大型主畫面小工具，也可放到最左側小工具頁。
- 條碼資料只供本機 App 與小工具顯示，不會傳送至開發者伺服器。

本 App 為獨立工具，與財政部及電子發票服務平台無隸屬或合作關係；不提供發票開立、儲存或兌獎功能。
